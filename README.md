# D.O.P.E.: Downstream Objective-Preserving Encoding

Compile a tabular dataset into a compact binary **program** that stores zero source rows and preserves downstream predictive transfer.

[![White Paper (PDF)](https://img.shields.io/badge/white%20paper-PDF-b31b1b.svg)](docs/whitepaper-v3/dope-v3.pdf)
[![CI](https://github.com/neverhuman/dope/actions/workflows/ci.yml/badge.svg)](https://github.com/neverhuman/dope/actions/workflows/ci.yml)
[![Jankurai full-audit score snapshot](docs/readme/jankurai.svg)](https://github.com/neverhuman/dope/actions/workflows/jankurai.yml)
[![License: MIT](https://img.shields.io/badge/license-MIT-blue.svg)](LICENSE)

- **Compact, self-contained artifacts:** `dope fit --format auto-v8` compiles a table with a declared target into a single binary program within the complete byte budget, storing zero source rows; `dope sample` generates synthetic rows on any CPU.
- **One signed CPU Rust executable:** No Python, PyTorch, or LibTorch required at runtime; signed Linux x86-64 releases carry GitHub/Sigstore OIDC attestations ([`dope-engine-v3.0.0`](https://github.com/neverhuman/dope/releases/tag/dope-engine-v3.0.0)).
- **Adaptive codec selection and twin-referenced ranking:** Per-table duplicate-grouped cross-fitting chooses between `Format 1` and the `DSE8` packet inside the byte cap, ranked against third-party generators on one headline Transfer Score ([white paper PDF](docs/whitepaper-v3/dope-v3.pdf)).

## Quick start

Install the [signed Linux x86-64 engine](https://github.com/neverhuman/dope/releases/tag/dope-engine-v3.0.0) with `gh v2.102.0` or newer (`scripts/install.sh` verifies `SHA256SUMS` and the GitHub/Sigstore OIDC signer, tag, and source commit before installing):

```bash
curl -fsSL https://raw.githubusercontent.com/neverhuman/dope/main/scripts/install.sh | bash -s -- --no-weights
dope doctor
dope fit train.csv --target y --format auto-v8 --budget 2048 -o model.dope
dope inspect model.dope
dope sample model.dope -n 1000 -o synthetic.csv
dope eval -m model.dope --train train.csv --test test.csv
```

Provide a CSV with an explicitly declared target ([target-last data contract](docs/data-contract.md)). One CPU Rust executable fits, inspects, samples, and evaluates the artifact with zero external weights, Python, or LibTorch at runtime. Optional `--v8-weights` loads an attested `SingleEncV8` SafeTensors checkpoint when supplied. Treat artifacts as derived data under your normal data-handling rules.
