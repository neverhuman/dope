# D.O.P.E.: Downstream Objective-Preserving Encoding

![Historical transfer and charged bytes, with the proposed frontier marked as unmeasured.](paper/generated/hero-frontier.png)

## Product and status

D.O.P.E. compiles a tabular training set into a compact sampling artifact. The research question is whether samples preserve predictive behavior for specified downstream learners, with every artifact byte accounted. It supports controlled transfer experiments; it is not a general-purpose data release or a substitute for the source table.

The measured evidence is a historical, selection-exposed validation study on PMLB regression tables. It establishes no released tier, TDL result, sealed-test result, or privacy status. The root [`paper/`](paper/README.md) package is the active TDL manuscript, specified but not measured. The PDFs in [`docs/whitepaper/`](docs/whitepaper/README.md) document frozen v2 evidence.

## Demonstration

Run the offline engineering fixture from the repository root:

1. `cargo build --locked --bin dope`
2. `target/debug/dope demo --out target/readme-demo.dpk --report target/readme-demo.json`
3. `target/debug/dope inspect --artifact target/readme-demo.dpk`
4. `target/debug/dope sample --artifact target/readme-demo.dpk --rows 500 --seed 1729 --out target/readme-synthetic.csv`

The fixture compiles a built-in simulated table, with no download or input file.
Use fresh output paths for another run. Its receipt explicitly reports that it
is unqualified and uncertified. Privacy, driver, and geometry checks are
unmeasured; runtime closure remains separate. The [public regression example](examples/public-regression/)
provides the UCI Airfoil acquisition and development recipe with its pinned
artifact byte decomposition. Neither example certifies a release.

## TDL protocol and privacy boundary

TDL is a proposed measure: the smallest tested dataset-specific byte budget meeting transfer, driver-agreement, and hard-gate thresholds across required auditor families. Its draft operating point requires at least nine-tenths transfer and four-fifths normalized driver agreement. Required families are boosted trees, neural models, and linear or additive models; tabular foundation models are planned and unqualified. The contract remains unfrozen and unmeasured, so no TDL result or gain is claimed. Missing or failed cells remain visible; a budget that never qualifies is unreached.

The historical privacy diagnostics cover particular samples and attacks. No formal-DP claim is made. No HIPAA-de-identification claim is made. Copy checks are separate gates. The official test split remains sealed for one preregistered run. Limits include PMLB-centered regression coverage, selection exposure, incomplete baseline families, and no external comprehension-review results.

## Reproduction and citation

Set up the research environment with `just setup`. Rebuild the historical paper with `just paper`; check generated evidence and figure consistency with `just paper-check`. These commands use committed, pinned evidence and require the repository's documented toolchain. For Rust and Python checks, run `just fast` and `just check`. A successful paper rebuild reproduces the historical study; it does not complete the proposed TDL campaign or unseal test data.

See [`paper/README.md`](paper/README.md) for the active manuscript, [metric specification](docs/metric.md), [claims policy](docs/claims-policy.md), and [testing guide](docs/testing.md). Cite the software with [`CITATION.cff`](CITATION.cff); identify every benchmark result as selection-exposed validation unless its evidence label says otherwise. Licensed model, dataset, and code details are recorded in the historical supplement and generated license inventory.
