# D.O.P.E.: Downstream Objective-Preserving Encoding

**Compile a table into a tiny generative program that keeps what models learn from it.**

[![CI](https://github.com/neverhuman/dope/actions/workflows/ci.yml/badge.svg)](https://github.com/neverhuman/dope/actions/workflows/ci.yml)

The score snapshot is checked against each fresh full-audit CI report; click it for current run status.

![Median robust retention against artifact bytes (log axis): the DOPE frontier, xz-compressed real rows at the same bytes, the earlier research kernel, and SDV Gaussian copula and ARF at default sizes.](bench/real-world/figures/hero.png)

DOPE reads a table and writes a few-kilobyte **program**: a standard
[safetensors](https://github.com/huggingface/safetensors) file that holds each column's
distribution, how the columns move together, and a compact model of the target. It stores no
rows. Train a model only on rows sampled from the program, test it on held-out *real* rows,
and on most public tables it keeps most of what the same model learns from the real table.

- **Small.** A program is a few kilobytes, tens to hundreds of times smaller than the
  SDV Gaussian copula, TVAE, CTGAN and ARF generators at their default settings.
- **Keeps what models learn.** Models trained only on its samples keep most of the predictive
  gain of models trained on the real rows, measured for the worst of three model families.
- **Beats shipping the rows at small budgets.** At the smallest budgets its samples train
  better models than the real rows compressed with `xz` to the same bytes, on most tables.
  As the budget grows, the compressed rows catch up and then win.
- **One number to chase: TDL.** *Transfer Description Length* is the smallest tested
  artifact whose samples keep a target share of the predictive gain for every model family.
- **ML-ready output.** Categories become one-hot columns and numbers land on `[0, 1]` with
  outlier-robust scaling, or rows come back in original units and labels.
- **Pure Rust.** Fitting and sampling run on CPU. CUDA and Metal builds exist through
  [candle](https://github.com/huggingface/candle) but are not tested in CI. The artifact
  loads anywhere safetensors does.

Every number below comes from the benchmark records and is regenerated by a script; see
the table for the exact values and their intervals.

## Quick start

```bash
# Build the CLI (Rust toolchain from rustup; add --features cuda or metal for a GPU)
cargo install --locked --path engine/dope-cli

dope fit train.csv --target income -o model.dope        # compile (default budget 4 KiB) and self-audit
dope inspect model.dope                                  # what is stored, byte by byte
dope sample model.dope -n 10000 -o synthetic.csv        # original units and labels
dope sample model.dope -n 10000 --space ml -o ml.csv    # one-hot + [0,1], ML-ready
dope eval -m model.dope --train train.csv --test test.csv   # retention per model family
dope frontier --train train.csv --test test.csv -t income   # bytes vs retention, and TDL
```

`--budget 16k` buys a larger program; `--anonymize` replaces column names and labels
with positional codes; `--device cuda` runs on a GPU.

`--size small|medium|large` picks a preset cap; `--max-parameters N` caps stored values;
`dope fit-tiers` builds all three sizes ([details, Elo ranking](docs/model-sizes-and-elo.md)).
Scripting flags and signed Linux binaries: [engine/README.md](engine/README.md#recipes),
[docs/signed-engine-release.md](docs/signed-engine-release.md).

## How it works

```mermaid
flowchart LR
  T[(table)] --> I[intake: types, levels, robust scaling]
  I --> C[covariates: marginals and a regime copula]
  I --> Y[target: network, oblivious trees, noise]
  C & Y --> Q[bits: rate-distortion, self-audited split]
  Q --> A[[model.dope]]
  A --> S[sampler]
```

- **Intake** infers types, orders categorical levels by their link to the target, pools rare
  levels, applies `log1p` to skewed counts and scales every number robustly onto `[0, 1]`.
- **Covariates.** Quantile functions on a normal-score grid, joined by a regime mixture of
  Gaussian copulas that reproduces every marginal exactly.
- **Target.** A residual tanh network for smooth structure, boosted byte-coded *oblivious
  trees* for thresholds and interactions, then calibrated noise or labels.
- **Bytes.** A measured rate–distortion search sets each tensor's bit depth; a *self-audit*
  (fast learners trained on samples, scored on held-out training rows) picks the split
  between dependence and target; schema and codes are stored as one brotli stream.

Details: [engine/README.md](engine/README.md) and the manuscript.

## The KPI: Transfer Description Length

Retention compares a model trained on synthetic rows with the same model trained on the
real rows, both scored on untouched real rows:
`R = (L_null − L_synthetic) / (L_null − L_real)`; the robust score keeps the worst model
family. **TDL** is the smallest tested artifact (`KiB@T90/D80`) whose samples recover
nine-tenths of the real-trained lift in every family (T90) and four-fifths of the
real-trained feature-attribution agreement (D80). The benchmark here measures T90; D80 is
specified and not yet measured ([docs/metric.md](docs/metric.md)).

**Why this KPI.** For learners that converge on the synthetic distribution, retention
under log-loss *is* the share of the predictive information `I(X;Y)` the program keeps
(under squared loss, the share of `Var E[Y|X]`). TDL then estimates, on a grid of tested budgets,
how many bytes a table's predictive information needs, and DOPE spends its bytes on the
target model first.

## Use a DOPE artifact from Python

Standard safetensors with one tensor, a brotli stream ([format](engine/README.md#the-artifact)):

```python
import json, brotli                      # pip install brotli safetensors
from safetensors.numpy import load_file

blob = brotli.decompress(load_file("model.dope")["dope"].tobytes())
n = int.from_bytes(blob[:4], "little")
program = json.loads(blob[4:4 + n])      # schema, structure, bit widths, section list
```

## Scope

All results here are selection-exposed development validation on public tables, measured on
CPU; none is a sealed TDL result, and the TDL driver gate is not part of them
(cross-model feature-driver preservation: not yet measured).

- Retention is measured on held-out real rows of public tables; your table may differ,
  so measure it with `dope eval` before relying on a program.
- Copy, membership and attribute checks are empirical diagnostics, not formal differential
  privacy and not HIPAA de-identification. An engine artifact keeps column names, category
  labels and quantiles unless you pass `--anonymize`; treat it as derived private data.
- Each program is conditioned on one declared target; other targets get their own program.
