# D.O.P.E.: Downstream Objective-Preserving Encoding

DOPE fits a small **program** to a table with a declared target. The program generates synthetic training rows from fitted summaries and schema, without storing complete fitting records.

## Quick start

Install [signed DOPE `v3.0.0`](https://github.com/neverhuman/dope/releases/tag/dope-engine-v3.0.0) on Linux x86-64 with `glibc 2.39` or newer. No GitHub account is required. On Ubuntu, run `sudo apt-get install -y ca-certificates curl jq`. This block checks the installer, then places the binary at `$HOME/.local/opt/dope/3.0.0/bin/dope`.

```bash
(
  set -euo pipefail
  installer=$(mktemp)
  trap 'rm -f -- "$installer"' EXIT
  curl -q -fsSL --proto '=https' --tlsv1.2 -o "$installer" \
    https://raw.githubusercontent.com/neverhuman/dope/51df4554bc292c3ad59ec2099fccbbde19cffadc/scripts/install.sh
  printf '%s  %s\n' 808729d2382fc37fbdcf69520d808430536b858074387198920b250033baa213 "$installer" |
    sha256sum --check --status
  bash "$installer" --standalone-prefix "$HOME/.local/opt/dope/3.0.0" \
    --tag dope-engine-v3.0.0 --source-digest e15c415bad9554f7c419dd240aa670d1a79a27fe
)
```

### Run the toy example

This example checks the install on a toy table. The test rows stay separate from the fit.

```bash
(
  set -euo pipefail
  export LC_ALL=C
  dope="$HOME/.local/opt/dope/3.0.0/bin/dope"
  cd "$(mktemp -d "${TMPDIR:-/tmp}/dope-quick-start.XXXXXX")"

  fixture='BEGIN {
    print "a,b,y"
    for (i=first; i<end; i++) {
      a=(17*i%997)/997; b=(31*i%991)/991
      print a "," b "," 2*a+b*b
    }
  }'
  awk -v first=0 -v end=160 "$fixture" > train.csv
  awk -v first=160 -v end=200 "$fixture" > test.csv

  "$dope" --threads 1 fit train.csv --target y --format 1 --budget 2048 --seed 42 -o model.dope
  bytes=$(wc -c < model.dope)
  test "$bytes" -le 2048
  printf 'Artifact size: %s bytes\n' "$bytes"
  "$dope" --threads 1 sample model.dope -n 640 --seed 7 -o synthetic.csv
  "$dope" --threads 1 eval -m model.dope --train train.csv --test test.csv \
    --synth synthetic.csv --auditors linear --seed 7 --json evaluation.json
  printf 'Workflow files: %s\n' "$PWD"
)
```

The printed directory contains `train.csv`, `test.csv`, `model.dope`, `synthetic.csv`, and `evaluation.json`. Retention is `(null loss − synthetic loss) / (null loss − real loss)`.

### Use your own CSV

Declare the target by name and split duplicate rows as groups. The [fit and sample guide](docs/getting-started.md#fit-a-table) produces `model.dope` and `synthetic.csv` with `--format auto-v8`. The [held-out evaluation guide](docs/getting-started.md#evaluate-the-synthetic-csv) uses a separate `audit-schema.dope` to write `evaluation.json`.
