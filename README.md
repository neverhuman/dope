# D.O.P.E.: Downstream Objective-Preserving Encoding

**Compile a table into a tiny generative program that keeps what models learn from it.**

[![CI](https://github.com/neverhuman/dope/actions/workflows/ci.yml/badge.svg)](https://github.com/neverhuman/dope/actions/workflows/ci.yml)

The score snapshot is checked against each fresh full-audit CI report; click it for current run status.

![Median robust retention against artifact bytes (log axis): the DOPE frontier, xz-compressed real rows at the same bytes, the earlier research kernel, and SDV Gaussian copula and ARF at default sizes.](bench/real-world/figures/hero.png)

DOPE reads a table and writes a few-kilobyte **program**, a standard
[safetensors](https://github.com/huggingface/safetensors) file holding each column's
distribution, how the columns move together, and a compact model of the target. Train any
model only on rows sampled from it, test on held-out *real* rows, and it recovers most of
what the same model learns from the real table. The program stores no rows.

- **Most predictive structure per byte.** At the few-kilobyte budgets where DOPE operates,
  its samples train better models than the real rows themselves compressed with `xz` to the
  same size, and from two kilobytes up than the repository's earlier research kernel; the
  program is orders of magnitude smaller than other generators (figure above, tables below).
- **One number to chase: TDL.** *Transfer Description Length* is the smallest artifact
  whose samples keep a target share of the predictive gain for every model family.
- **ML-ready output.** Categorical strings become one-hot columns and numeric columns land
  on `[0, 1]` with outlier-robust scaling, or rows come back in original units and labels.
- **Pure Rust, CPU or GPU.** Fitting and sampling run on CPU, CUDA or Metal through
  [candle](https://github.com/huggingface/candle); the artifact loads anywhere safetensors does.

## Quick start

```bash
# Build the CLI (Rust toolchain from rustup; add --features cuda or metal for a GPU)
cargo install --locked --path engine/dope-cli

dope fit train.csv --target income -o model.dope        # compile (default budget 4 KiB) and self-audit
dope inspect model.dope                                  # what is stored, byte by byte
dope sample model.dope -n 10000 -o synthetic.csv        # original units and labels
dope sample model.dope -n 10000 --space ml -o ml.csv    # one-hot + [0,1], ML-ready
dope eval -m model.dope --train train.csv --test test.csv   # retention per model family
dope frontier --train train.csv --test test.csv -t income   # bytes vs retention, and TDL
```

`--budget 16k` buys a larger program; `--anonymize` replaces column names and labels
with positional codes; `--device cuda` runs on a GPU.

## How it works

```mermaid
flowchart LR
  T[(table)] --> I[intake: types, levels, robust scaling]
  I --> C[covariates: marginals and a regime copula]
  I --> Y[target: network, oblivious trees, noise]
  C & Y --> Q[bits: rate-distortion, self-audited split]
  Q --> A[[model.dope]]
  A --> S[sampler on CPU, CUDA or Metal]
```

- **Intake** infers types, orders categorical levels by their link to the target, pools rare
  levels, applies `log1p` to skewed counts and scales every number robustly onto `[0, 1]`.
- **Covariates.** Quantile functions on a normal-score grid, joined by a regime mixture of
  Gaussian copulas that reproduces every marginal exactly.
- **Target.** A residual tanh network for smooth structure, boosted byte-coded *oblivious
  trees* for thresholds and interactions, then calibrated noise or labels.
- **Bytes.** A measured rate–distortion search sets each tensor's bit depth; a *self-audit*
  (fast learners trained on samples, scored on held-out training rows) picks the split
  between dependence and target; schema and codes are stored as one brotli stream.

Details: [engine/README.md](engine/README.md) and the manuscript.

## The KPI: Transfer Description Length

Retention compares a model trained on synthetic rows with the same model trained on the
real rows, both scored on untouched real rows:
`R = (L_null − L_synthetic) / (L_null − L_real)`; the robust score keeps the worst model
family. **TDL** is the smallest tested artifact (`KiB@T90/D80`) whose samples recover
nine-tenths of the real-trained lift in every family (T90) and four-fifths of the
real-trained feature-attribution agreement (D80). The benchmark here measures T90; D80 is
specified and not yet measured ([docs/metric.md](docs/metric.md)).

**Why this KPI.** For learners that converge on the synthetic distribution, retention
under log-loss *is* the share of the predictive information `I(X;Y)` the program keeps
(under squared loss, the share of `Var E[Y|X]`). TDL is then the number of bytes a table's
predictive information needs, and DOPE spends its bytes on the target model first.

## The research kernel and the equal-byte study

Two engines share the metric. [`engine/`](engine/) (`dope`) is the DOPE engine above.
[`rust/`](rust/) (`dope-kernel`) is the research kernel behind the TDL protocol, the frozen
evidence and the equal-byte study below, which pits smaller kernel programs against more
generators and against the most real rows that fit in exactly their bytes. Those results
describe the kernel, not the engine above.

- **The smallest generator at its transfer level.** On the historical 99-table panel the published DOPE run keeps 0.89 of the real gain for the worst of three learners at 1,895 B. TabSyn keeps 0.88 with 22,301x the bytes, and no generator's frontier is above DOPE's at any budget.
- **More than the real rows that fit in its bytes, once a table outgrows the program.** On the 9 tables in the historical mixed/unknown-origin cohort that reach the study's cap of 2,000 fit rows, a program keeps 0.38 [0.12, 0.69] more of the real gain than the most real rows that fit in exactly its bytes (8 wins, 0 losses, 1 within 0.01), and real rows need a median 4.3x its bytes to match it. The advantage grows with how much larger the whole table is than the program (Spearman 0.78 over 26 tables); tables of a few hundred rows compress to about a program's size and are cheapest shipped whole, so over all 26 tables the gap is 0.02 [-0.04, 0.15] (14 wins, 9 losses).
- **Checked against the obvious objections.** The real-row arm gets the best of three lossless codecs, an exact byte match, and an MLP also trained on the rows resampled to the synthetic size (early-stopped on held-out rows). The 0.38 is for the worst of three learners; per learner on the large tables it is 0.10 (least squares), 0.10 (MLP), 0.04 (CatBoost). Leaving the MLP out, the large-table gap is 0.18 [0.12, 0.69] (8 wins, 1 loss). On all 97 panel lineages, simulated families included, it is 0.24 on the 38 large tables (36 wins, 0 losses).
- **Where it stops.** A program this small is a lossy channel: its retention plateaus, so to clear the 0.8 bar real rows need fewer bytes on 14 of 26 tables (DOPE on 6), and at 0.9 on 19 (DOPE on 6). Raising that ceiling at fixed bytes is the open problem.
- **Honest bytes, no GPU.** Packed values make the same programs 1.85x smaller with bit-identical samples for the headline shape; with the column scaling charged as two 4-byte floats per column the median charge is 676 B (2,666 B before). From 250 to 16,000 rows a program stays between 598 and 1,148 B while the whole table grows to 88,166 B. The network trains in Rust; its CatBoost retention shows no systematic shift from the published GPU run (median difference 0.000 over 96 tables, tenth to ninetieth percentile -0.40 to 0.22; different splits, not a paired replay).

### Kernel quick start on a real table

```bash
cargo build --release --bin dope-kernel                     # Rust toolchain pinned in rust-toolchain.toml
python3 examples/adult/prepare.py --out target/adult        # UCI Adult, CC BY 4.0, official test split
target/release/dope-kernel fit-table --csv target/adult/train.csv --target income --out target/adult/adult.dope
target/release/dope-kernel inspect-table --model target/adult/adult.dope
target/release/dope-kernel sample-table --model target/adult/adult.dope --rows 32561 --out target/adult/synthetic.csv
pip install numpy pandas scikit-learn catboost
python3 examples/adult/evaluate.py --dir target/adult --model target/adult/adult.dope
```

`synthetic.csv` keeps original units, categories, dates and missing markers, with the explicitly declared target always last. The evaluation fits logistic regression, an MLP and CatBoost on real rows, on DOPE rows, and on as many real rows as fit in the artifact's bytes, then scores all of them on the official test file. Replace the CSV and `--target` to run your own table; `--drop` removes identifier columns.

### How the kernel normalizes a raw table

`fit-table` stores an invertible plan per column, so samples decode back to the source schema:

- **Numbers** scale to the unit interval; log scaling gives skewed columns more useful resolution.
- **Categories** use one code per column, ordered by smoothed target mean. Downstream learners apply one-hot encoding; independently sampled dummies could violate the single-category constraint.
- **Dates** use day counts. Missing cells stay missing; multiple rare levels pool together. Identifier-like columns are dropped and reported.

Numeric tables already on the unit interval can use `dope-kernel compile` directly, and `dope-kernel compile-csv` remains for the typed raw and mixed carriers ([CLI](docs/cli.md)).

### What changed in the kernel

- **Native training.** The headline residual network trains in Rust with the published optimizer settings; no libtorch or GPU is needed (`--native-target-profile`).
- **Packed values.** The artifact header records a quantization grid, so values are stored as grid codes (`--packed-codec`): about half the bytes, with bit-identical samples for the headline program shape.
- **Table workflow.** `fit-table`, `sample-table` and `inspect-table` give the end-to-end path above.

The study behind the numbers is in [research/benchmark/equal_bytes](research/benchmark/equal_bytes/README.md) and the mathematics in [docs/math.md](docs/math.md).

## Use a DOPE artifact from Python

Standard safetensors with one tensor, a brotli stream ([format](engine/README.md#the-artifact)):

```python
import json, brotli                      # pip install brotli safetensors
from safetensors.numpy import load_file

blob = brotli.decompress(load_file("model.dope")["dope"].tobytes())
n = int.from_bytes(blob[:4], "little")
program = json.loads(blob[4:4 + n])      # schema, structure, bit widths, section list
```

## Scope

All results here are development validation on public tables, not a sealed TDL result: the
kernel's official test split stays sealed for one pre-registered run, and cross-model
feature-driver preservation: not yet measured.

- Retention is measured on held-out real rows of public tables; your table may differ,
  so measure it with `dope eval` before relying on a program.
- Copy, membership and attribute checks are empirical diagnostics, not formal differential
  privacy and not HIPAA de-identification. An engine artifact keeps column names, category
  labels and quantiles unless you pass `--anonymize`; treat it as derived private data.
- Each program is conditioned on one declared target; other targets get their own program.
