# Additive v4 producer and objective

`research.levels.v4_model.V4Model` consumes declared NC1 public schemas (at most256 expanded columns), FIT-only matrices and explicit native landmark provenance. Its group-aware multiset encoder pools semantic groups equally, emits descriptor256 + task128 + distribution128, and retains every input column. Padding is removed using row masks and actual schema width before any moment, quantile or solve. FIT regression targets must be NC1 [0,1]; real training-query tails stay unclipped.

`NativeLandmarks` accepts the frozen native recipe with source-report/FIT-scope hashes and observed masks, or explicit `none`. It never synthesizes a report from correlations. Input dropout is a subset of actual observations; auxiliary supervision retains the separately recorded observed native values. Production/native admission remains the source/report owner's responsibility; public test reports establish conformance only.

The served graph is exactly D07's independent grouped marginals and six gated blocks: linear[p], asinh[p], periodic[p], hinge[p], adjacent pair[p-1], row mean[1]. Target coefficients occupy all5p coordinates. Regression noise is uniform with variance1 and explicit learned scale; classification has class-specific coefficients/intercepts. All gates and target parameters are on wire. No neural residual executes at the recipient.

`sample_differentiable` uses the served fixed-draw schedule. Numeric quantile interpolation is differentiable. Categorical and missing draws use exact hard forward values with an explicitly biased CDF straight-through gradient estimator. This is not a claim of differentiating the true discrete wire distribution without approximation. `synthesize_then_learn_loss` fits a differentiable ridge probe on generated rows, then scores disjoint gradient-query rows; its driver loss compares grouped permutation effects on those same query rows. The caller supplies explicit `LossWeights`; no campaign hyperparameters are selected by this implementation. Outer TEST/sealed/tune roles are refused. Scientific evaluation still uses DVS and independently admitted real queries.

Trainer adapter: `encode_batch(x_fit[B,N,P],y_fit[B,N],row_mask[B,N],schemas,native_reports,keep_masks=None)` returns cell states. Strip query padding similarly, generate draws[Nsyn,2G+1] from captured Torch RNG and average each cell objective's `total` into trainer callback key `loss`. `V4Trainer` owns data/budget/checkpoint/RNG and actual optimizer updates. Half-precision Gram/solve inputs are promoted to FP32; no GPU performance claim is made.

`export_packet(model,state,level=...)` exports fully closed DML4 parameters and enforces the full byte cap. It rejects stale states after model mutation, private/unknown graph fields and invalid target/group values. Weight/recipe/conditioning/FIT identities remain distinct. Payloads need no source, owner ScaleCard or encoder checkpoint for sampling. Legacy v3 code, weights and conditioning remain untouched.

Public synthetic producer fixtures are generated by `python3 -B -m research.levels.tools.export_v4_conformance --out NEW_DIR`; existing directories are refused. Their manifest binds source hashes, producer weights/recipe, draw artifacts and Torch version. Zero optimizer updates and zero real-data reads are explicit. Python analytic tests and actual Rust `mlc_v4_producer_parity` verify sampler equivalence; no fixture establishes retention, privacy, throughput, model qualification or release permission.
