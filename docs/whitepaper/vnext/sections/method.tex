\section{Rate-risk compiler}
Selection sees development sources and development learners only.
Audit labels stay outside the producer repository.
Unknown acquisition, redistribution, or training rights, and unknown prior-design or contamination exposure, leave the confirmation protocol unfrozen.

\begin{verbatim}
procedure RateRiskCompile:
    inputs: development sources, learners, and byte constraint
    candidates := decoded generators allowed by rights
    sensitivity := development-learner transfer loss
    allocation := serialized bytes by development sensitivity
    artifact := freeze the allocated decoded program
    return artifact

procedure Confirm:
    inputs: artifact, withheld sources, withheld learners
    require the source-family protocol to be frozen
    return original-unit loss on the withheld cells
\end{verbatim}

\noindent The pseudocode is a hypothesis about allocation.
It is not a report of a fit.
The frozen artifact is identified only after a later packet binds code, rights, and receipts.
