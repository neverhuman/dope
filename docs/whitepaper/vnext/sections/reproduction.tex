\section{Reproduction}
Four levels are specified in \path{docs/vnext/REPRODUCE.md}.
None of them is measured in this draft.

\paragraph{Inspect.}
Read the draft, the claim ladder, and the development source registry.
Do not fit a model.

\paragraph{Report replay.}
Recompute a published summary from a bound receipt.
The receipt identity is \TBD{replay-receipt}.

\paragraph{One-cell metric recompute.}
Recompute original-unit loss for one frozen development cell.
The loss is \TBD{one-cell-loss}.

\paragraph{Full refit.}
Refit only after rights, code, and budget locks are frozen.
The outcome is \TBD{full-refit}.
Repository lock names live in \path{docs/testing.md} and \path{production/kpi-contract.json}.
This section does not restate those quotas.
