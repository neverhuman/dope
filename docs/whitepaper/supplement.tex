\section{Executable MFS-v3 conformance}
\label{app:conformance}
The release score uses the contract's weighted geometric mean with a component
floor: $100\exp(\sum_i w_i\log\max(s_i,\epsilon)/\sum_i w_i)$, clipped to
$[0,100]$. The components lie in $[0,1]$. A failed gate yields a null scalar.
The matched null is the median linear-MSE candidate among three deterministic
independent-marginal tables. Linear losses and candidate selection are fixed
before any representation encoder forward. This is a median selector; a
learnability band is outside this implementation.
The near-copy floor is the declared quantile of nearest-other squared distances
among distinct real fit rows in the shared map, with linear interpolation.

\section{Public data and scored-artifact availability}
\label{app:public-kit}
A credential-free upstream-data path is
\path{python3 -m research.benchmark.fetch_pmlb --list} and
\path{python3 -m research.benchmark.fetch_pmlb DATASET_ID OUTPUT_DIRECTORY}.
It authenticates PMLB data against an upstream Git LFS SHA pin at a fixed public
revision. The public manifest includes every prepared lineage's PMLB identifier
and the historical train/validation/test split hashes from the committed data
lock. Downloads stay upstream source data: the historical JopeDime staging
used a separate hybrid coreset and target-stratified selection, whose exact
selected row indices were omitted from the captured receipts. The public fetch
therefore provides source datasets and historical split identities, while exact
historical partition reconstruction requires the missing selection manifest.

The originally scored model files and synthetic rows have no published bundle.
The captured historical metadata has artifact digests and charges but omits a
complete portable inventory binding every scored file to a retrievable public
object. Publishing current scratch files under those identities would require
an additional custody audit; logged replay fits have different artifact
identities. The verified alternative for all displayed paper numbers is the
committed validation ledgers, original metadata and compressed numeric logs,
authenticated by the input pins and rebuilt by \texttt{just paper}. This
reproduces paper reductions and figures; it leaves original model sampling and
historical partition reconstruction as explicit packaging limitations.
