\begin{abstract}
\noindent DOPE turns a table with a declared target into a file that can generate synthetic rows without storing any of the input rows. It fits a compressed program and an analytic codec within the same \VThree{BudgetBytes}-byte whole-file limit and chooses between them on the fitting rows.
We measure how well models trained on the synthetic rows predict targets on real test rows. A Transfer Score of \VThree{ScoreScale} corresponds to training on a second real sample of the same size as the fitting split.
On fresh row splits of development tables (\VThree{CandCells} informative cells in \VThree{Families} lineage families), DOPE~\VThree{ReleaseVersion} scores \VThree{CandScore} when sampling \VThree{PrimaryMult}$\times$ as many rows as it saw during fitting. Its median file is \VThree{CandBytesMed}~bytes and every file fits the cap.
Under the same cap, uniformly retaining and resampling fitting rows gives \CapScore{\RowsBudget}{score} [\CapScore{\RowsBudget}{low}, \CapScore{\RowsBudget}{high}] on these splits.
Four generators fitted with library defaults and no byte cap score lower on the same cells: ARF at \VThree{ArfScorePoint}, and SDV's Gaussian copula, TVAE and CTGAN at \VThree{GcScorePoint}, \VThree{TvaeScorePoint} and \VThree{CtganScorePoint}. Their median files are \VThree{MethodsRatioMin} to \VThree{MethodsRatioMax} times larger.
Paired intervals favor DOPE over all three SDV generators across two sets of row splits from the same tables. The interval against ARF includes zero on both at \VThree{PrimaryMult}$\times$.
A copy of the fitting rows scores \VThree{CopyAScorePoint} on the report splits. Every generator's rows are readily distinguishable from real rows, and the privacy results are empirical audits on these data.
\end{abstract}
