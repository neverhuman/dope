\section{Reproducibility}\label{sec:repro}

\paragraph{From receipts to this paper.}
Three links, each checked by a tool rather than by hand:
{\sloppy % long monospace paths: stretch spacing rather than run into the margin
\begin{enumerate}
  \item \texttt{dope\_kpi primary} and \texttt{compare} write the receipts under \path{bench/real-world/results/scoreboard/v3.0.0/}: \path{primary.json} and \path{primary-methods.json} (SHA-256 prefixes \texttt{\VThree{PrimarySha}} and \texttt{\VThree{MethodsPrimarySha}}), \path{compare-methods.json}, and the four pairs of DOPE against each generator in \path{evidence/paper/}. Each is sorted-key JSON that records the SHA-256 of the contract, the schedule and every rows file read.
  \item \texttt{dope\_kpi render-readme}, \texttt{render-hero} and \texttt{render-paper-tables} turn those receipts into the README block, Figure~\ref{fig:hero} and Tables~\ref{tab:ranking} and~\ref{tab:paired}; \path{render-manifest.json} records the README's SHA-256s and \path{tools/claims/dope1.py} \texttt{-{}-check} refuses drift.
  \item \path{docs/whitepaper-v3/scripts/render_v3_paper.py} writes every \texttt{\textbackslash VThree} macro from the receipts, the contracts and constants parsed from the Rust sources, and fails unless every DOPE row equals the README block's. Third-party rows must repeat the release receipts' run and arms and agree with the run's \path{MANIFEST.json}, and each pair in \path{evidence/paper/} must be the sign reversal of its row in \path{compare-methods.json}. It converts the hero SVG to PDF, records both SHA-256s and records the SHA-256 of both generated tables.
\end{enumerate}\par}

\paragraph{What continuous integration checks.}
\texttt{render\_v3\_paper.py -{}-check} fails on drift of a generated file or the hero PDF, an undefined macro, a typed claim the receipts no longer support, a digit typed outside a macro, citation, label or short allowlist, or a section that cites an earlier DOPE release's arms or numbers.
The \texttt{paper-clean} job rebuilds the generated files and PDF with fixed timestamps and requires a zero diff; \path{docs/whitepaper-v3/README.md} lists the commands.
