\subsection{Which codec the released selector chose}
The signed replay selected Format~1 on \FormatRouteValue{fits} fits and analytic \texttt{DSE8} on \AnalyticRouteValue{fits} fits across the full schedule. Every packet matched its recorded digest. No neural packet was selected. Table~\ref{tab:chosen-codec} summarizes the headline cells within each group, using the same underlying score rows and guard ledger as the overall release result.
