## 0. What the five specs agree on (themes)

1. **One public truth.** README says v4, paper says v3, active evidence is v2. Freeze MFS-v2/v3/v4 as *historical*; no new public metric versions until the new contract lands (S1 §1, S2 §1.2A, S3 P0.1, S4 §2.3, S5 §2.5).
2. **Replace the weighted MFS master score** with a *task-conditioned rate–distortion* object: the **smallest artifact (in exact bytes) whose lower-confidence transfer AND driver fidelity both pass frozen thresholds**, plus the full byte→transfer frontier. Non-compensatory gates, not weights (S1 §2, S2 §3, S3 §7–8, S4 §4, S5 §3/§5.5).
3. **Bytes are the independent variable** with ≥2 scopes: dataset-specific payload (primary) + cold sampling closure (+ optional amortized). `encoded_numbers` never ranks anything. Canonical container, charge manifest, runtime file-access trace, adversarial accounting tests (S1 §5, S2 §4, S3 Part III, S4 §5, S5 §5).
4. **Transfer protocol:** null-normalized paired TSTR/TRTR retention, informative-task gate for low-signal tasks, auditor-family robust (worst/min-family) aggregation, cluster bootstrap LCBs, held-out learner families and held-out source families (S1 §3, S2 §5, S3 §5, S4 §4, S5 §3).
5. **Driver fidelity:** model-agnostic grouped (conditional) permutation importance evaluated on the *real* test set, normalized by real-vs-real stability, rank/mass/sign/interaction components; never raw cross-model SHAP (S1 §4, S2 §6, S3 §6, S4 §7, S5 §4).
6. **Auditor registry, not hard-coded constants;** typed lock state machine (specified→…→qualified); Kumo/Mitra/TabICL/TabPFN/LimiX/TabDPT are *unqualified* until admitted; frozen core panel + rolling frontier panel (S1 §6, S2 §7, S3 §14–16, S4 §6, S5 §7.4–7.5).
7. **Benchmark redesign:** author-default / equal-compute / rate-constrained tracks; real datasets dominate the headline; PMLB = mechanism lab; shift/OOD and stress cohorts; all failures retained; sealed test opened once (S1 §7–10, S2 §8–10, S3 Part V, S4, S5 §7).
8. **Claims firewall:** one machine-readable results file generates README+paper numbers/figures; every row has an evidence status; CI fails on hand-typed numbers, unqualified headline models, mixed cohorts (S1 §15.5/§17, S2 §13.16/§21, S3 §51–52, S5 §14).
9. **README** = short landing page (thesis, hero frontier, 3–4 command quick start, result card, limitations, citation; ≤250 lines); MFS algebra/ops diary moved out (S1 §12, S2 §15, S3 Part IX, S4, S5 §10).
10. **Paper** = new canonical `paper/` package (main + supplement), new title/abstract/Figure 1 frontier; old `dope-mfs.tex` and audits archived (S1 §13, S2 §17, S3 Part X, S5 §11).
11. **Open-source quality:** public CI for forks, CONTRIBUTING/SECURITY/THIRD_PARTY/governance, wheels/binaries, SBOM, citation, one-command reproduction (`just paper`, `just benchmark-smoke`, `just verify-release`) (S1 §17, S2 §18, S3 Part XII, S5 §14.4).
12. **Compiler** optimizes the frontier: byte budget first-class input, Pareto/beam search, gain-per-bit allocation, progressive artifact, multi-auditor worst-family selection, classification support (S2 §11, S3 Part VII, S5 §8).
