# Explicit next-version workflows

These additive CPU interfaces preserve historical v3, metric v1/v2 and DPK decoding. The named NC1 recipe is separate from the historical prepared-coordinate receiver. No engineering fixture grants model, privacy, throughput or release qualification.

`dope normalize fit --request FIT_REQUEST.json --out NEW_PRIVATE_DIRECTORY` fits a frozen owner ScaleCard from explicitly declared FIT rows. The request contains `table`, `declared`, `fit_rows` and optional `options` (the native NC1 types). Outputs contain a private ScaleCard and FIT matrix, a public schema and a receipt. The owner retains the private directory. Public schema/group identifiers contain no original names, extrema or categories. All-missing declared nominal input retains OTHER/MISSING coordinates; declared Integer remains Integer.

`dope normalize apply --card PRIVATE_CARD.json --request APPLY_REQUEST.json --out NEW_PRIVATE_DIRECTORY` applies the frozen card without fitting. The request contains `table`, `rows` and `features_only`; apply emits a new private directory. `dope normalize inverse-target --card PRIVATE_CARD.json --request VALUES.json --out NEW_VALUES.json` inverts regression targets without clipping; its request is an object with a `values` array. Never send the owner card to a recipient. Files are created without overwrite; Unix private outputs use restrictive permissions. Parse and validation errors return static codes.

`dope mlc-v4 pack --input PACKET.json --out NEW_PACKET.dml4` validates the complete public DML4 graph and hard tier cap. `dope mlc-v4 inspect --packet PACKET.dml4` prints its public identity/schema summary. `dope mlc-v4 sample --packet PACKET.dml4 --rows 10 --seed 17 --out NEW_SAMPLE.json` samples entirely from the packet. The recipient needs neither encoder weights, source rows nor the owner card. All six gates, marginals, target coefficients and noise are serialized; no model download or hidden default completes the graph. See [the producer contract](v4-producer.md).

`dope transfer-report --request DVS_REQUEST.json --out NEW_REPORT_DIRECTORY` evaluates strict prepared evidence and writes `receipt.json` plus `AuditCard.md`. New requests must supply `declared_roles` with FIT/TUNE/TEST usages and the canonical role-binding digest described in [DVS](dvs.md); absent or mismatched bindings refuse before selection and produce no report. The request records every scheduled cell and actual paired losses. Missing/failed cells remain in the denominator; ties with no informative real ordering yield ineligible/null rank. C02 simultaneous full-family bounds and explicit positive floors remain required. Artifact accounting hashes actual supplied bytes; empirical nearest-neighbor diagnostics are not formal privacy. Missing qualification, privacy or lineage evidence remains visible in the card. See its schema.

The research `V4Trainer` supports CPU optimizer updates only. `V4ObjectiveAdapter` consumes explicit loss weights, the actual v4 model and disjoint gradient-query rows; row/column padding masks are distinct from native landmark dropout `bool[B,23]`. Checkpoints bind typed data bytes, schema, roles, memberships, report observations, weights, configuration and RNG. Invalid resume is refused before changing destination state. The optional pinned CUDA transfer helper does not establish CUDA training support.

Run `SHARED_PYTHON=python3 bash ops/ci/shared-levels.sh torch test_next_version` for bounded public Python conformance. Native focused commands live in `agent/test-map.json`; `just check-all` retains both ordinary kernel and engine gates. Full exact-head CI and the separate [qualification readiness hold](plans/v4-qualification-readiness.md) remain required. No command here launches a training campaign.

High-required landmark execution preserves the consumed High conditioning vectors and reserves the full-panel baseline before spectrum admission. Effective conditioning digest equality concerns its documented vector-only domain. Skipped FINE cells, observation masks, work accounting and private report bytes remain different; bundle/report identity is not inferred from vector parity. The default full-panel constructor remains the historical route. Native fixture execution is required before a parity claim.
