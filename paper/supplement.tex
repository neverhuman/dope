\section{Metric contract}
\label{app:contract}
The machine-readable contract is \path{contracts/tdl-contract-v1.json} with its schema in
\path{schemas/}. It records the transfer equation, the informative-task floor, the
thresholds (\HeadlinePoint{}, $\tau_T = $ \TauT, $\tau_D = $ \TauD), the byte grid
(\ByteGrid), the required and held-out learner families, the payload and closure policy,
the seed design (\SeedDesign), the multiplicity procedure, evaluator isolation, and
\texttt{protocol\_frozen}. While any field is unresolved, \texttt{protocol\_frozen} stays
false. The human-readable definitions are in \path{docs/metric.md}.
The thresholds above are generated from the executable contract. Candidate revisions are
separate from the current draft and do not change historical receipts. No contract in
this manuscript authorizes a sealed run.

\section{Result states and gates}
\label{app:states}
A cell or method reports exactly one state:
\begin{itemize}
  \item \texttt{qualified};
  \item \texttt{not\_reached\_in\_tested\_range};
  \item \texttt{unqualified};
  \item \texttt{incomplete};
  \item \texttt{failed}.
\end{itemize}
Hard gates are conjunctive: exact and near copy, cleartext scan, positive
lift over the predictor-only and independent-marginal controls, a reconciled byte ledger,
verified clean-room sampling, and complete qualified auditor families. The empirical attack
panel is required for release certification, which is reported separately.

\section{Statistical plan}
\label{app:stats}
Cluster bootstrap over source family, dataset and seed with \BootstrapReplicates{} replicates, a
fixed generator seed (\BootstrapSeed) and shared resample indices across auditor families; the
one-sided \LowerBoundLevel{} lower bound is a lower order statistic of the replicates, and a
driver component counts only when its real-versus-real ceiling reaches \StabilityFloor. These values
are read from the \ContractState{} contract \ContractId. Golden fixtures hold the Rust core and the
Python mirror to identical outputs. The multiplicity family remains unresolved and must freeze before confirmation. Preserve
the same source-family and global fit-seed draws across methods and auditors when a seed
acts on the whole panel. Resampling seeds independently within each dataset can omit
shared variation. Required informative coverage, null calibration and stability floors
must also be declared before low-signal cells can be adjudicated.

\section{Falsifiable method tests}
\label{app:ablations}
These are proposed development experiments, not measured improvements. Freeze their
selection rule before choosing a successor; keep confirmation rows sealed.
\begin{description}
  \item[Feature screening.] Compare current univariate screening with the explicit
  interaction-screen successor on interaction-only, additive and rare-effect tasks at
  the same encoded byte cap. Count false selections and retained holdout lift.
  \item[Residual uncertainty.] Compare no-noise, Gaussian, fixed heavy-tail, compact
  mixture and monotone-quantile profiles using out-of-fold residuals. Evaluate original-unit
  tail loss and conditional coverage beside average transfer. Calibrated noise need not
  improve a squared-error learner.
  \item[Dependence.] Hold the target model fixed and ablate independence, a tree, a copula
  and richer families. Include a predictor-only control and conditional errors.
  \item[Quantization.] Compare precision and component allocation after encoding,
  including transform and dictionary state. Measure improvement in the worst development
  learner family per added byte rather than uncharged parameter counts.
  \item[Preprocessing.] Compare affine, support-aware invertible and quantile transforms
  inside fit folds. Preserve original target units; nonlinear target transforms define a
  different learner recipe. Test nominal category relabeling invariance.
  \item[Attribution.] Permute dummy columns of an original feature together. Test
  correlated substitutes and interaction groups against the real-versus-real ceiling;
  prediction agreement is not causal driver recovery.
\end{description}
For squared error, applying the same invertible affine target map to fixed truths and
predictions multiplies every loss by the same squared scale, which cancels in retention.
This evaluation identity does not say that retraining is invariant to scaling. Clipping
query targets or changing their nonlinear loss violates the comparison.
