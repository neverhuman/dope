\section{Result states and gates}
\label{app:states}
A cell or method reports exactly one state:
\begin{itemize}
  \item \texttt{qualified};
  \item \texttt{not\_reached\_in\_tested\_range};
  \item \texttt{unqualified};
  \item \texttt{incomplete};
  \item \texttt{failed}.
\end{itemize}
Hard gates are conjunctive: exact and near copy, cleartext scan, positive
lift over the predictor-only and independent-marginal controls, a reconciled byte ledger,
verified clean-room sampling, and complete qualified auditor families. The empirical attack
panel is required for release certification, which is reported separately.

\section{Statistical plan}
\label{app:stats}
Cluster bootstrap over source family, dataset and seed with \BootstrapReplicates{} replicates, a
fixed generator seed (\BootstrapSeed) and shared resample indices across auditor families; the
one-sided \LowerBoundLevel{} lower bound is a lower order statistic of the replicates, and a
driver component counts only when its real-versus-real ceiling reaches \StabilityFloor. These values
are read from the \ContractState{} contract \ContractId. Golden fixtures hold the Rust core and the
Python mirror to identical outputs. \pending{Multiplicity family, fixed when the contract freezes.}

\section{Reversible table encoding and the quick-start ablation}
\label{app:encoding}
The compiler reads a numeric matrix on the unit interval with the target last; the quick start's
encoder (\path{examples/quickstart/dope_tables.py}) maps a raw table to it from the fit rows only and
inverts it exactly for categorical codes. A categorical column with few levels becomes one-hot
columns with the most frequent level as the dropped reference, because a full set of dummies sums
to one and is collinear with the intercept of the compiler's closed-form read-out. Any larger categorical column becomes one
target-ordered code, its levels placed by smoothed mean target with a small rank term that keeps
every code distinct. Skewed non-negative columns are log-transformed and every numeric column is
clipped at Tukey's far-out fences, never tighter than its outer percentiles, before rescaling.
Table~\ref{tab:ablation} reports every configuration of the ablation that chose these defaults,
on UCI Adult (fit rows subsampled per seed, official test file as query rows) and UCI Abalone
(a seeded split per seed). Transfer-in-the-loop selection scores the backends
\texttt{chow\_liu}, \texttt{compact\_neural\_residual\_symbolic}, \texttt{sparse\_gaussian\_copula}
and the built-in tournament by three-fold train-on-synthetic, test-on-held-out-fit-rows retention
with a linear and a gradient-boosted auditor, and compiles the winner on all fit rows. Evidence:
local engineering ablation on two public tables.
