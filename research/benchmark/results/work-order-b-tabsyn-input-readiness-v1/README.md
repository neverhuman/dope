# TabSyn common metric input readiness

The frozen sample ledger retains 143 admitted recipes, 39 unavailable outcomes
and 418 unstarted cells. Every admitted recipe was reconstructed from original
fit/sample process, completion, exit, source, runtime-reference and TRAIN-only
kind receipts. The new metadata bridge passed that reconstruction; numeric
inputs and learned artifacts were not opened. The exact counts, seed/size
groups and immutable receipt hashes are in `readiness.json`.

This result is preparation for the shared fidelity, detection and empirical
privacy evaluator. No expanded metric operation or scientific fit was started.
Physical input hashes, runtime providers, fresh capacity and an admitted worker
remain required. Historical parent exit, MFS-v2, PTF-v1, release-safe L3 and
superiority remain null. The selected configuration is the scaled author
default, with no new native tuning or winner claim. Official tests stay sealed.

The controlled metadata replay used a 256 MiB memory limit. The service's
reported peak and its recorded cgroup peak differ; this ledger makes no full
resource-peak claim and does not charge preparation as generator fit cost.

Validate with the schema and run the source controls listed in the benchmark
README. Detailed input paths, rows, samples, models and metadata recipe bodies
