## Pilot-only AIM amendment

After frozen queue admission, `aim_adapter.py` established a fixed public eight-bin domain for the common numeric projection and an artifact-only sample path. Its author-default model size and iteration cap are retained, while `epsilon=1` and `delta=min(10^-5,1/n^2)` are explicit. The source tarball, adapter, and runtime version lock are pinned in the supplemental package. `runner.py` accepts this method only when the job has `pilot_only: true`; the original 42-cell matrix and blocked queue receipts are unchanged. The fit tests execution cost and serialization only. Training-fitted projection bounds consume private data before AIM, so this path does **not** establish an end-to-end DP guarantee. The pinned configuration, discretization, artifacts, and public validation evidence still need an external accounting audit before final comparison.

The News TabPC probe used the author's custom-data training code with its published dataset-specific architecture, but installed Torch 2.7.0 differs from upstream's requested 2.9.1. A separate receipt correction records that the measured VRAM is sampling peak only. It confirms large artifact and source-row retention on this dataset; it is not a validated final adapter or a scoreable comparison cell.
