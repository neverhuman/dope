# Jankurai working standard for DOPE

The user's task and the repository `AGENTS.md` control the work. The pinned
v1.7.1 full scan must score at least 85, pass, apply no caps, and report no
high or critical findings. `just score` regenerates boundary evidence before
the scan. `just fast-audit` is an advisory edit loop.

## Ownership boundaries

Read `agent/owner-map.json` before editing and keep a single writer in each
worktree. Rust owns the V3 compiler, certification, and release decision.
Python V1 and offline external learners have dated, proved boundaries in
`agent/boundaries.toml`; neither can publish a V3 release.

## Proof lanes

Use `agent/test-map.json` for changed paths. `just focus <filter>` is the
narrow Rust loop. `just check` runs locked Rust tests, Clippy, contract drift,
the retained Python fixtures, and budget checks. The CI CPU, security, and
full audit jobs are required. Scheduled GPU evidence controls claims for GPU
backends and sealed-corpus promotion.

## Generated zones

`production/kpi-contract.json` is the frozen v2 input. `build.rs` validates
and embeds its digest and tier constants; `ops/ci/check-contracts.sh` checks
the generated values and the read-only v1 fixture. Edit the source contract
and regenerate evidence, rather than editing generated bytes in `target/`.

## Repair receipts

CLI failures emit source-data-free typed hints. The full scan emits JSON,
Markdown, a repair queue, a hash-only attestation, and a disposition for each
baseline fingerprint under `target/jankurai/`. Use the reported rerun command
and keep failed evidence. `docs/audit.md` records the narrow historical wire
term exception and the score gate.
