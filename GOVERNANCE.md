# Governance

Jepson Taylor is the project owner. Maintainers review changes, maintain evidence
and contracts, and steward releases. Contributors propose changes through issues
and pull requests. Scientific protocol choices, license admission, protected-test
access and publication remain explicit owner decisions; an implementation or a
passing fixture does not approve them.

A change lands only after the required checks pass on its exact commit, an
independent reviewer approves that commit, and the owner has seen material scope
changes. Maintainers preserve reviewable commits and evidence. No history rewrite,
release tag, sealed evaluation, or model admission is implied by a refactor.

The pending decisions and working defaults are recorded in
[docs/decisions.md](docs/decisions.md) and the
[rebuild TODO](docs/internal/TODO-2026-10-15.md). Working defaults support implementation;
they do not freeze the scientific protocol. [STATUS.md](STATUS.md) records the
current evidence labels. All new headline claims must pass the claims registry,
registry qualification, cohort and byte-accounting gates.

Discuss disagreements in the issue or pull request with reproducible evidence.
Escalate unresolved scope or protocol decisions to the owner. Report misconduct
privately as described in [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md); report
vulnerabilities through [SECURITY.md](SECURITY.md).
